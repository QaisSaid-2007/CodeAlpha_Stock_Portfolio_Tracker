# 📈 Stock Portfolio Tracker

A Python-based **Stock Portfolio Tracker** developed as part of my **Python Programming Internship at CodeAlpha**.

The application simulates a stock market environment and allows users to create accounts, buy and sell stocks, track their portfolios, and calculate their investment performance.

---

## 🚀 Features

### 👤 User Management

- Create a new user account
- Login system
- Password reset functionality
- Username validation
- Automatic portfolio creation with an initial balance of **$10,000**

### 📊 Stock Market

- Display available stocks
- Display current stock prices
- Simulate stock price movements
- Randomly increase or decrease stock prices
- Store stock market data in Excel

### 💰 Portfolio Management

- Buy stocks
- Sell stocks
- Track owned shares
- Track remaining balance
- Calculate portfolio value
- Calculate profit percentage
- Store portfolio information in CSV

### 📈 Data Visualization

The application uses **Matplotlib** to visualize the user's investments.

The portfolio chart displays:

- Stock tickers
- Percentage of owned shares
- Total number of shares
- Investment value
- Profit percentage
