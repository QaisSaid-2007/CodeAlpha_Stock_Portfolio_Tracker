
# 📈 Stock Portfolio Tracker — Python Project

A console-based **Stock Portfolio Tracker** built with Python, Object-Oriented Programming (OOP), Pandas, and Matplotlib. The application allows users to manage stock investments, buy and sell shares, track their balance and profit, and visualize their portfolios.

---

## 📖 Project Overview

This project was developed as part of my **Python Programming Internship at CodeAlpha**. It simulates a stock market and provides a simple system for managing user accounts and stock portfolios using CSV and Excel files.

---

## 🎯 Purpose of the Project

- Practice Object-Oriented Programming in Python.
- Implement account creation, login, and password resetting.
- Simulate stock price fluctuations.
- Manage stock purchases, sales, and user balances.
- Store and manipulate data using Pandas, CSV, and Excel.
- Visualize investments using Matplotlib.

---

## 💼 Main Features

- **Account Management:** Sign up, log in, and reset passwords.
- **Stock Market:** View available stocks and simulated prices.
- **Buy Shares:** Purchase shares and update the available balance.
- **Sell Shares:** Sell owned shares and receive the proceeds.
- **Portfolio Tracking:** Track investments, balance, and profit percentage.
- **Data Visualization:** Display investment distribution using a pie chart.

### File Descriptions

- **`DataBases.py`** — Loads and manages stock market data, user information, and portfolio visualization.
- **`BluePrint.py`** — Defines abstract base classes for the application's structure.
- **Excel file** — Stores stock market data and prices.
- **CSV files** — Store user account information and portfolio data.

## ⚙️ Installation

**1. Clone the repository**

```bash
git clone https://github.com/QaisSaid-2007/CodeAlpha_Stock_Portfolio_Tracker.git
cd CodeAlpha_Stock_Portfolio_Tracker
```

**2. Install the required libraries**

```bash
pip install pandas matplotlib openpyxl
```

## ▶️ How to Run

Run the main program:

```bash
python MainProgram.py
```

Follow the instructions displayed in the terminal to create an account, manage investments, buy or sell shares, and view your portfolio.
